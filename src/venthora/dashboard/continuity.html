Continuity checking…

What VENTHORA does when a server dies or something dangerous happens: one server at a time may pay (the writer lease), safe mode stops every payment that runs by itself, and a standby takes over only after it has locked every payment Airwallex already knows, so nothing is paid twice.

Safe mode

Stops the scheduled run, payment on arrival and the autopilot until it is lifted. A person can still approve and pay one request. The reason is written to the audit trail.

Standby

Taking over: the standby takes the lease, turns safe mode on, reads the last transfers from Airwallex and locks each one, then reads the last 24 hours of mail again. Safe mode stays on until the FCO lifts it.

Only the FCO (Super admin) changes anything here.
