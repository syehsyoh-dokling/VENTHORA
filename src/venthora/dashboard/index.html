Document validation

Local Python reads the email, the PDF text, every image placed on a page (stamp, signature) and the PDF's own dates; the AI model (Settings → AI model) adds which document each file is, the invoice date and anything an auditor would question, always quoting the document. A failed Required check holds the request for a person; Warn flags it.

Bank details in your name at Airwallex, one per currency. Give them to customers on invoices: they pay by a local transfer, and the money lands in the wallet as a deposit (it shows on the Dashboard as cash in).

Admin team

Who runs each level. The super admin is the FCO at head quarters: sees everything and may do everything. An HQ admin works company-wide; a country office, branch or project finance admin works only in its own unit and the units under it, and gives only roles below its own.

Local model (vLLM)

A model on your own machine or GPU server, through any OpenAI-compatible server: vLLM, Ollama, LM Studio, llama.cpp. Nothing leaves your network.

Start a server

vLLM (GPU): vllm serve Qwen/Qwen2.5-7B-Instruct --port 8000 → http://127.0.0.1:8000/v1
Ollama: ollama run qwen2.5:7b → http://127.0.0.1:11434/v1
LM Studio: start the local server → http://127.0.0.1:1234/v1
This laptop: python scripts/local_llm_server.py --port 8003 → http://127.0.0.1:8003

AI model

How the model is used

  • It reads emails, PDFs and the inbox, and proposes values with the words it read them from.
  • Code keeps a value only if that quote is in the source and the value is inside it; otherwise it is dropped.
  • When the model and the rules disagree, a person decides. It never sets an amount or moves money.
  • A hosted provider receives the email and PDF text, so it needs your confirmation first.
  • Keys are kept on this machine (git-ignored) and never shown again: only their last four characters.
  • Nothing saved here: MODEL_ENDPOINT / MODEL_NAME in .env apply.
