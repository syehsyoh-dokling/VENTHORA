AI model

How the model is used

  • It reads emails, PDFs and the inbox, and proposes values with the words it read them from.
  • Code keeps a value only if that quote is in the source and the value is inside it; otherwise it is dropped.
  • When the model and the rules disagree, a person decides. It never sets an amount or moves money.
  • A hosted provider receives the email and PDF text, so it needs your confirmation first.
  • Keys are kept on this machine (git-ignored) and never shown again: only their last four characters.
  • Nothing saved here: MODEL_ENDPOINT / MODEL_NAME in .env apply.
